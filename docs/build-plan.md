## Method, per module

1. Export every frame from the Figma web app as "CSS (all layers)" and SVG into `HRango2/Design/<module>` with an `INDEX.md` (the connector cannot read these files); read the requirement notes under `HRango/requirements/HRango - UI design/Design`.
2. Replace the placeholder route with stubs (layout, index redirect, pages), a mock handlers file registered in `src/mocks/handlers.ts`, and the nav entry.
3. An agent builds the module from the exports: exact copy, colours, sizes, icons cut from the SVGs; mock API with validation and coherent data flow; Vitest coverage of each list and its main actions; loading / empty / error states; usable at phone width.
4. Review in the browser at desktop and phone widths, run tsc / eslint / the whole suite, document the departures in the README, then commit.
